S3-NAS · USB disk network storage

ติดตั้ง S3-NAS ผ่านเบราว์เซอร์

เสียบแฟลชไดรฟ์หรือกล่อง HDD เข้าบอร์ด ESP32-S3 ให้เป็นที่เก็บไฟล์ในบ้าน อัปโหลด/ดาวน์โหลดผ่านหน้าเว็บได้ทุกเครื่องในวง WiFi เดียวกัน บอร์ดไม่มีจอ ตั้ง WiFi ผ่านมือถือ ติดตั้งครั้งแรกหรืออัปเดตจากคอมพิวเตอร์ (Chrome หรือ Edge) หรือมือถือ Android (Chrome กับสาย OTG) ไม่ต้องลงโปรแกรม

เวอร์ชัน …ฟรีใช้ในวง LANชื่อไฟล์ภาษาไทยตั้ง WiFi ผ่านมือถือฟอร์แมตดิสก์บนเว็บ
เบราว์เซอร์นี้ใช้ไม่ได้
เปิดหน้านี้ด้วย Google Chrome หรือ Microsoft Edge บนคอม หรือ Chrome บนมือถือ Android · iPhone และ iPad ติดตั้งไม่ได้ (Apple ไม่เปิดให้เว็บใช้พอร์ต USB) แต่ใช้งาน NAS ผ่านเว็บได้ตามปกติหลังติดตั้งแล้ว

สิ่งที่ต้องมี

  • บอร์ด ESP32-S3-WROOM-1 N16R8 (flash 16MB, PSRAM 8MB) แบบ DevKitC-1 ที่มี USB-C 2 ช่อง ชื่อ COM กับ USB · รุ่น flash 8MB ใช้ไม่ได้
  • หัวแปลง OTG USB-C (ผู้) → USB-A (เมีย) สำหรับเสียบดิสก์ที่ช่อง USB
  • ดิสก์: แฟลชไดรฟ์ หรือกล่อง HDD ที่มีอแดปเตอร์ไฟของตัวเอง · ใหญ่สุด 2TB · ไฟล์ละไม่เกิน 4GB (FAT32) · ยังไม่ใช่ FAT32 ฟอร์แมตบนหน้าเว็บได้
  • แฟลชไดรฟ์ต้องได้ไฟ 5V จากบอร์ด: หยดตะกั่วเชื่อมจุด USB-OTG 2 จุดหลังบอร์ด (ใกล้ช่อง USB) · กล่อง HDD บางรุ่นก็ต้องการ
  • ที่ชาร์จมือถือ 5V 2A กับสาย USB-C เส้นสั้นและหนา สำหรับเสียบใช้งานจริง และ WiFi 2.4 GHz · สายบาง/ยาว/เก่า ไฟตกระหว่างอัปโหลดไฟล์ใหญ่ บอร์ดจะรีบูตเอง (หน้าเว็บขึ้นเตือน ⚡)
บัดกรีจุด USB-OTG แล้ว ไฟเข้าได้ทางเดียว: เสียบสายคอมหรือที่ชาร์จที่ช่อง COM เท่านั้น ช่อง USB ไว้เสียบดิสก์ ห้ามเสียบสายจากคอม/ที่ชาร์จเข้าทั้ง 2 ช่องพร้อมกัน ไฟจะชนกัน คอมหรือบอร์ดอาจเสีย · แนะนำเสียบหัวแปลง OTG ค้างไว้ที่ช่อง USB กันเสียบผิด

1. เสียบบอร์ด

  1. เสียบสายที่ช่อง COM (ชิป USB-Serial CH343) · ช่อง USB ใช้ติดตั้งไม่ได้
  2. คอม: ใช้สาย USB ที่ส่งข้อมูลได้ และปิดโปรแกรมอื่นที่อาจใช้พอร์ต เช่น Arduino IDE, PlatformIO, Serial Monitor
  3. มือถือ: ใช้สาย USB-C ↔ USB-C หรือหัวแปลง OTG (OPPO, realme, vivo บางรุ่นต้องเปิด “การเชื่อมต่อ OTG” ในตั้งค่าก่อน)

2. เลือกแบบติดตั้ง

ไฟล์ในดิสก์ USB ไม่ถูกแตะ ไม่ว่าเลือกแบบไหน (ถอดดิสก์ออกระหว่างติดตั้งก็ได้)

3. ติดตั้ง

กดปุ่มแล้วเลือกบอร์ด (ชื่อมักเป็น “USB Single Serial”, “CH343” หรือ COM) แล้วกดเชื่อมต่อ

ใช้เวลาประมาณ 1–2 นาที (แบบล้างเครื่อง 3–4 นาที) อย่าถอดสายหรือปิดจอมือถือระหว่างนี้
ค้างที่ “กำลังเชื่อมต่อ” หรือขึ้นสีแดง: ทำให้บอร์ดเข้าโหมดแฟลชด้วยมือ แล้วกดติดตั้งใหม่
  1. กดปุ่ม BOOT บนบอร์ดค้างไว้ (อย่าปล่อย)
  2. กดปุ่ม RST แล้วปล่อย 1 ครั้ง
  3. ปล่อยปุ่ม BOOT
  4. รีเฟรชหน้านี้ แล้วกด “เชื่อมต่อบอร์ดและติดตั้ง” ใหม่
ตั้งค่าขั้นสูง / บันทึกการทำงาน

  2. เอามือถือต่อ WiFi ชื่อ S3-NAS-Setup (ไม่มีรหัส) หน้าตั้งค่าจะเด้งขึ้นเอง (ไม่เด้ง: เปิด http://192.168.4.1)
    3. 
      
  3. เลือก WiFi บ้าน ใส่รหัส กด “เชื่อมต่อ” · ต่อติดแล้วหน้าจะโชว์ไอพีและรหัสเข้าเว็บ จดไว้หรือแคปหน้าจอ (hotspot ปิดเองใน 1 นาที)
    4. 
      
  4. ต่อมือถือ/คอมกลับเข้า WiFi บ้าน แล้วเปิด http://s3-nas.local หรือไอพีที่จดไว้ · เปลี่ยนรหัสได้ที่ปุ่ม ⚙
    5. 
      
  5. ลืมไอพีหรือรหัส / ย้าย WiFi: กดปุ่ม BOOT บนบอร์ดค้าง 3 วินาที hotspot S3-NAS-Setup จะกลับมา หน้าตั้งค่าโชว์ไอพีและรหัสปัจจุบัน
    6. 
    

    
ใช้ในวง LAN เท่านั้น อย่าเปิด port ออกอินเทอร์เน็ต (HTTP ไม่เข้ารหัส)
