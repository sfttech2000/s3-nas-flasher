S3-NAS คู่มือการใช้งาน
======================

S3-NAS เปลี่ยนบอร์ด ESP32-S3 กับแฟลชไดรฟ์หรือ HDD ทาง USB เป็นที่เก็บไฟล์ในบ้าน
เปิดหน้าเว็บจากคอมหรือมือถือที่อยู่ในวง WiFi เดียวกัน แล้วอัปโหลด ดาวน์โหลด จัดการไฟล์ได้
บอร์ดไม่มีจอ: ตั้งค่าทุกอย่างผ่านมือถือ


1. ต่อสาย
---------
  ช่อง COM  = เสียบไฟ (ที่ชาร์จมือถือ 5V 2A) หรือสายคอมตอนติดตั้ง
  ช่อง USB  = เสียบดิสก์ ผ่านหัวแปลง OTG (USB-C ผู้ -> USB-A เมีย)

- แฟลชไดรฟ์ไม่มีไฟเลี้ยงของตัวเอง: ต้องหยดตะกั่วเชื่อมจุด USB-OTG 2 จุดหลังบอร์ด
  ให้ไฟ 5V ออกไปที่ช่อง USB (กล่อง HDD บางรุ่นก็ต้องการ แม้มีอแดปเตอร์ของตัวเอง)
- ** บัดกรีแล้ว ไฟเข้าได้ทางเดียว: ห้ามเสียบสายคอมหรือที่ชาร์จเข้าทั้ง 2 ช่องพร้อมกัน **
  เสียบหัวแปลง OTG ค้างไว้ที่ช่อง USB จะได้ไม่เผลอเสียบผิด
- HDD 3.5" ต้องใช้อแดปเตอร์ไฟของกล่องเอง บอร์ดจ่ายไฟให้ไม่พอ
- ใช้ที่ชาร์จ 5V 2A กับสาย USB-C เส้นสั้นและหนา (เช่นสายที่ติดมากับที่ชาร์จ)
  สายบาง ยาว หรือเก่า ไฟจะตกตอนอัปโหลดไฟล์ใหญ่ บอร์ดรีบูตเองกลางทาง
  ถ้าเป็นแบบนี้ หน้าเว็บจะขึ้นแถบเตือน ⚡ ไฟเลี้ยงไม่พอ -> เปลี่ยนสาย/ที่ชาร์จ
- แฟลชไดรฟ์ USB 3.0 รุ่นใหม่กินไฟมากกว่ารุ่นเก่า ยิ่งต้องใช้สายและที่ชาร์จดี


2. ตั้ง WiFi ครั้งแรก
---------------------
- เปิดเครื่องครั้งแรก บอร์ดเปิด WiFi ชื่อ S3-NAS-Setup (ไม่มีรหัส)
- เอามือถือต่อ S3-NAS-Setup หน้าตั้งค่าจะเด้งขึ้นเอง
  (ไม่เด้ง: เปิดเบราว์เซอร์ไปที่ http://192.168.4.1)
- แตะเลือก WiFi บ้าน ใส่รหัส กด "เชื่อมต่อ" (ใช้ได้เฉพาะ WiFi 2.4 GHz)
- ต่อติดแล้ว หน้าจะโชว์
    ไอพี           เช่น http://192.168.1.50
    ชื่อ           http://s3-nas.local
    ล็อกอิน        ชื่อผู้ใช้ admin และรหัสผ่าน (สุ่มให้ตอนเปิดครั้งแรก)
  จดไว้หรือแคปหน้าจอ hotspot จะปิดเองใน 1 นาที
- ใส่รหัส WiFi ผิด: หน้าบอกว่าต่อไม่ได้ แก้แล้วกดใหม่ได้เลย
- ไอพีคงที่ (ไม่บังคับ): กด "ไอพีคงที่" ในหน้าตั้งค่า


3. ลืมไอพี / ลืมรหัส / ย้าย WiFi
--------------------------------
- กดปุ่ม BOOT บนบอร์ดค้าง 3 วินาที -> WiFi S3-NAS-Setup กลับมา
  ต่อแล้วหน้าตั้งค่าจะโชว์ไอพีและรหัสปัจจุบัน หรือเลือก WiFi ใหม่ได้
- WiFi บ้านหลุด บอร์ดต่อใหม่เอง · ต่อไม่ได้นาน 2 นาที บอร์ดเปิด S3-NAS-Setup ให้เอง
- http://s3-nas.local ใช้ได้บนคอม Windows, Mac และ iPhone
  Android บางเครื่องใช้ไม่ได้ ให้ใช้ไอพีแทน


4. หน้าเว็บ
-----------
- อัปโหลด: ปุ่ม "อัปโหลด" หรือลากไฟล์มาวางบนหน้าเว็บ
- อัปโหลดทั้งโฟลเดอร์: ปุ่ม "อัปโหลดโฟลเดอร์" หรือลากโฟลเดอร์มาวาง
- ระหว่างอัปโหลด อย่าปิดหน้าเว็บ และอย่าให้คอมเข้าโหมด sleep
  (หลุดกลางทาง ไฟล์ที่ค้างจะถูกลบทิ้ง ต้องเริ่มใหม่)
- ดาวน์โหลด: ปุ่ม ⬇ · แตะชื่อไฟล์ = เปิดดูในเบราว์เซอร์ (รูป, PDF, วิดีโอ, ข้อความ)
- เปลี่ยนชื่อ ✏ (ใส่ /โฟลเดอร์/ชื่อ เพื่อย้าย) · ลบ 🗑 (โฟลเดอร์ต้องว่างก่อน)
- ⚙ เปลี่ยนรหัสผ่าน / ฟอร์แมตดิสก์


5. ดิสก์
--------
- ใช้ระบบไฟล์ FAT32 · ไฟล์ละไม่เกิน 4GB · ดิสก์ใหญ่สุด 2TB
- ดิสก์ที่เป็น exFAT / NTFS บอร์ดอ่านไม่ได้: แถบด้านบนของหน้าเว็บจะมีปุ่ม "ฟอร์แมต"
- ฟอร์แมต: ⚙ > ฟอร์แมตดิสก์ > ดูชื่อและขนาดดิสก์ให้ถูกลูก > พิมพ์คำว่า ลบทั้งหมด > กดฟอร์แมต
  ** ข้อมูลในดิสก์หายทั้งหมด กู้คืนไม่ได้ ** · ระหว่างฟอร์แมตห้ามถอดดิสก์
- ดิสก์ที่ฟอร์แมตจากบอร์ด เสียบคอม Windows อ่านได้ตามปกติ


6. ข้อควรรู้
-----------
- ความเร็วราว 0.3 MB/s (1GB ราว 1 ชั่วโมง) เหมาะเก็บรูปและเอกสาร
- ใช้ในวง LAN เท่านั้น อย่าเปิด port ออกอินเทอร์เน็ต (HTTP ไม่เข้ารหัส)
- อัปเดตเฟิร์มแวร์: เปิดหน้าติดตั้งแล้วเลือก "อัปเดต" ค่า WiFi รหัส และไฟล์ในดิสก์ยังอยู่
  ติดตั้งเสร็จแล้วถ้าบอร์ดมองไม่เห็นแฟลชไดรฟ์ ให้ถอดแฟลชไดรฟ์แล้วเสียบใหม่
